# Error Museum

The Error Museum stores compact regression evidence for prediction failures that reached or nearly reached production behavior.

Each case must say whether it contains a full raw ADS-B replay or only a decision-level reconstruction. Missing feed coverage is never rewritten as a successful prediction or a miss.

Current v4.2 case:

- `v42-ist-arrival-false-alert-2026-09-18.json` — IST-arrival early-alert failure reconstructed from Railway decision telemetry for THY2GN and THY7ER.
