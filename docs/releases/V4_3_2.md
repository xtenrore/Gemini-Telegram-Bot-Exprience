# Plane Alerts v4.3.2

v4.3.2 corrects Next60 Prediction Lab outcome matching. The previous shadow resolver could select the spatially closest point from an entire same-day callsign route, even when that point belonged to a different occurrence several hours away from the forecast.

## Changes

- Bound outcome matching to the stored expectation window plus the existing 15-minute outcome grace on each side.
- Never fall back to an unrelated same-day route point when the bounded interval has no observation.
- Keep no-observation cases unresolved with `actual_pass = null`, preserving the rule that missing ADS-B coverage is not a success or miss.
- Add bounded fallback matching for older expectation documents that lack explicit window fields.
- Quarantine legacy outcomes whose selected CPA falls outside their own bounded expectation interval.
- Preserve quarantined values under `legacy_*` fields for forensic analysis while clearing them from accuracy scoring.
- Add an Error Museum case and regression coverage for QNT576-style multi-hour wrong-occurrence matches.

This release changes Prediction Lab shadow evaluation only. It does not change live trajectory, CPA, ETA, qualification, cancellation or alert timing.
